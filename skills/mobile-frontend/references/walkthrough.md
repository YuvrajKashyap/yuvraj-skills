# Example walkthrough

On a transit timetable, swipe to the next route, then tap the previous-route control. The title, selected indicator, URL if deep-linked, and departures should agree after each action. Try a diagonal swipe while scrolling a long list. Opening the stop filter should bring its field into view without covering the results. Dismiss it and check where focus lands. Repeat with large text, reduced motion, and the phone rotated.
