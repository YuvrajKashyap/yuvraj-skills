# Brief for one direction

Use this as a working note for a single builder or as the assignment for one parallel contributor.

- **Product and audience.** Who is arriving, what are they trying to do, and which facts or brand commitments must survive the redesign?
- **Direction.** Give the concept a name. Describe its visual medium, how the visitor moves through it, and why the idea belongs to this product.
- **Experience.** Describe the opening, a memorable interaction, the primary action and its confirmation, and how the design carries through the last screen. Include touch, keyboard, and reduced-motion behavior.
- **Implementation.** State the owned folder, entry point, preview base path, shared content and action interfaces, and available dependencies. Name who handles changes shared across directions.
- **Evidence.** Return the preview address, the journey exercised, any failures or untested states, and the weakest part worth a second pass.

For the second pass, give a concrete observation. For example, if the hero promises an interactive map but selecting a location opens a generic card, connect the selection, map position, and detail view so the interaction delivers on that promise.
