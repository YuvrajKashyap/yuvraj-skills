# Yuvraj Skills

Reusable skills for AI agents, curated from a larger private collection. Each skill contains a `SKILL.md` and any supporting files it needs. Check your agent's documentation for its skill discovery location and restart or refresh if needed.

| Skill | Purpose | Source |
| --- | --- | --- |
| [max-frontend](skills/max-frontend) | Build expressive, reactive frontends with cinematic animation and premium visual craft | Original |
| [unslop](skills/unslop) | Edit writing for clarity and remove formulaic language | [Cursor plugins](https://github.com/cursor/plugins/tree/main/pstack/skills/unslop) |
| [handoff](skills/handoff) | Prepare a concise handoff for another agent | [Matt Pocock](https://github.com/mattpocock/skills/tree/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/productivity/handoff) |
| [systematic-debugging](skills/systematic-debugging) | Investigate bugs and verify fixes | [Superpowers](https://github.com/obra/superpowers/tree/22f0b463e7a5e579904dd6211a520321035526f7/skills/systematic-debugging) |

Handoff and systematic debugging include local portability adaptations. Each package retains its own upstream license; no blanket license covers this repository. Inspect instructions and scripts before running them. Availability and behavior depend on your agent and environment.
